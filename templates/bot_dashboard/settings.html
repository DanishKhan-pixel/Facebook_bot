Settings Guide
What are Bot Settings?

Bot settings control how your Facebook ID creation tasks behave. You can configure various parameters like delays, retry attempts, and automation preferences.

Important Notes:
  • Settings are applied to all new tasks
  • Changes don't affect running tasks
  • Use descriptive names for easy identification
  • Test settings with small tasks first
